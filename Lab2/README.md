# Lab 2 — Array Algorithms

## Files
- `FindMax.java` — Finds the maximum value in an array and its index.
- `PairSum.java` — Finds a pair of numbers (brute force) summing to a target value.

## How to Run
Compile and run each file independently:

javac FindMax.java
java FindMax

javac PairSum.java
java PairSum
